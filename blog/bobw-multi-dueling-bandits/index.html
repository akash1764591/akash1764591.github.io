Best-of-Both-Worlds
Multi-Dueling Bandits

S Akash · August 10, 2026 · 5 min read

this is a short note on our paper. i wanted to write down the two reductions that made the result click for me.

the problem

we study multi-dueling bandits: in each round, the learner chooses several arms and sees only the winner. one example i kept in mind was comparing search rankers. several rankers produce results, one is preferred, and everything about the remaining comparisons stays hidden.

the basic tension is between learning quickly and staying robust. with stable preferences, it makes sense to settle on a good option early. with adversarially changing preferences, the same confidence can become expensive. the learner does not know in advance which regime it is in.

our question was whether one algorithm could use stable preferences without becoming fragile when that stability disappears. this is the best-of-both-worlds objective.

from a group comparison back to a duel

the useful observation for Condorcet was a small reduction. if an ordinary dueling algorithm asks to compare \(x\) and \(y\), while the interface expects four items, we submit \(\{x,x,y,y\}\). we report “\(x\) won” whenever either copy of \(x\) is selected.

this duplication weakens the preference signal, but does not reverse it. a true \(70\)-\(30\) preference becomes roughly \(63\)-\(37\). with a group of \(m\) items, every margin is multiplied by the same positive factor:

\[ \widetilde P_t(x,y)-\tfrac12 =\beta_m\!\left(P_t(x,y)-\tfrac12\right) \]

the factor \(\beta_m\) lies between \(1/2\) and \(1\), so every head-to-head winner is preserved. that is enough to place a standard dueling algorithm inside the multi-way interface. we call the resulting wrapper MetaDueling.

condorcet and borda behave differently

the Condorcet and Borda objectives use different information. a Condorcet winner beats every other option directly, while a Borda winner has the best average performance against all opponents.

MetaDueling is enough for the Condorcet objective because only the direction of each pairwise comparison matters. Borda is harder: its score depends on information spread across the entire preference matrix, so preserving the winner of one duel is not enough.

learn quickly, but keep checking

Borda needed a second idea. in SA-MiDEX, we first sample broadly enough to build a baseline and then eliminate arms that are clearly worse. a small monitoring process keeps checking whether that baseline still agrees with the observations.

as long as the observations agree with the baseline, SA-MiDEX gets the efficiency of the stochastic setting. if the monitor finds sustained drift, it switches to MiDEX, which keeps exploring and can handle adversarially changing preferences.

random noise is the annoying part: it can look like drift for a while, so the switching threshold has to be conservative. a persistent change eventually grows beyond ordinary fluctuation, and that is when the algorithm gives up the stochastic assumption.

how i think about the result

i now think about the result in two pieces: duplication handles the mismatch between winner-only group feedback and ordinary duels, while monitoring handles the mismatch between the stochastic and adversarial regimes.
